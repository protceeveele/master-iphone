1. Sostituisci i file del repository GitHub Pages con questi.
2. Mantieni sounds/ con i tuoi WAV.
3. Su iPhone crea un Comando Rapido chiamato esattamente MASTER END.
4. Dentro MASTER END metti per ora solo: Attendi 1 secondo.
5. Disattiva Non disturbare per far aprire l'URL e osserva cosa succede a fine animazione.

Questa versione tenta l'autostart. iOS può comunque bloccare l'audio automatico senza gesto utente.
Alla fine apre: shortcuts://run-shortcut?name=MASTER%20END
