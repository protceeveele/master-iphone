MASTER PWA per iPhone 14

1) Copia in sounds/:
stdout.wav
granted.wav
theme.wav
expand.wav
keyboard.wav

2) Pubblica gratis su GitHub Pages:
- crea un repository, es. master-ios
- carica TUTTI i file di questa cartella
- Settings > Pages > Deploy from a branch > main / root

3) Su iPhone:
- apri il sito Pages in Safari
- Condividi > Aggiungi alla schermata Home
- apri MASTER dalla Home

Nota: iOS non offre un trigger pubblico 'telefono sbloccato', quindi questa PWA non può partire automaticamente a ogni Face ID/unlock senza un trigger alternativo di Comandi Rapidi.
L'audio web può richiedere il primo tap su START MASTER per le policy autoplay di iOS.
